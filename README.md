# WEBテスト計算トレーナー

WEBテストの計数（図表の読み取り）を時間内に解くための、暗算・概算スピード練習Webアプリです。

**▶ https://oyuaki.github.io/webtest-quickcalc/**

![WEBテスト計算トレーナー](ogp.png)

## 特徴

- 割合・増減率・倍率・分数↔%・逆算・大小比較など、図表の読み取りで頻出の計算11カテゴリ
- 選択肢なし。頭の中で解いて答えを表示し、○（暗算で正解）／△（筆算・メモで正解）／×（不正解）で自己採点
- カテゴリ別の目安時間と、正答率・筆算依存率・平均時間の記録
- 苦手カテゴリを多めに出題、ミス・遅い問題の復習
- 10問／20問／30問セット、3分・5分スプリント
- キーボード操作（Enter / Space / 1・2・3 / Esc）、スマホ・ダークモード対応
- 登録不要。記録はブラウザ内（localStorage）にのみ保存

## ローカルで使う

`index.html` をブラウザで開くだけです。ビルド不要・外部ライブラリなし。
